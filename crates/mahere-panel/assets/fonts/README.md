# Label fonts

Static cuts for map lettering (Nick 2026-10-14: a few base fonts, ASCII only, so a theme can set its own type).
Each is one weight (300, 400, 500, 600, 700) of an open font, instanced from its variable master where it has one, subset to printable ASCII plus the middle dot, degree, multiplication sign and right quote, hinting dropped; letters outside fall back to the panel's Open Sans.
Cut with fontTools from the google/fonts repository, 2026-10-14.
